# Current design/authority decisions

Latest owner directions control this packet. Earlier advice is superseded where inconsistent.

**Selected by owner:** name First Encounter; hands-first; one shared combatant for human and NPC; first ground exchange before kicks/Grab, then Punchlines, then environmental spectacle; independent copied-runtime repo; browser Codex; existing assets and targeted new art; minimal administrative interruptions.

**Controls are experimental:** R readiness; LMB light/intercept; short RMB release heavy only with fists up; long hold reach; sustained grips for people/nodes but latched items; wheel guard, later throw wind; F contextual kicks/knee; Q communication. Earlier RMB guard/F heavy/Q Grab suggestions are obsolete. Final voice correction explicitly keeps bindings loose.

**Proposed test defaults:** all numerical timings, sparring nonlethal policy, Momentum experiment, guard stepping, dev-swap binding, source/module layout and exact initial art choices. Codex may tune within this scope and record the changes without routine owner reapproval. Do not portray these numbers as user-locked rules.

**Deferred, not rejected:** Punchline stakes and BASED vulnerabilities; KeyWrapping-derived opportunity; clinch win/escape/reversal; jumps, bicycle kicks, universal physical attachment; throws and weapons; collapsing floors and vehicles; city scale. These ideas are kept out of the current acceptance gate so the first exchange can exist.

**Authority:** new game workspace may modify its copied runtime under current owner permission. Canonical original repositories and the packet's vendor/raw assets are preserved. Later Lab phases, canonical promotion and remote account permission bypasses are not authorized by this packet.
