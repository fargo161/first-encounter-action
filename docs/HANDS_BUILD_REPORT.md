The five focused donor suites and the separately extended Claude findings suite passed. The latter still records four legacy design findings. The hands builder explicitly reads UTF-8 and emits LF bytes.

The 25 rules checks and 11 browser scenarios passed. The real-input exchange included guarded lights, a timed interception, a counter palm and guard break/recovery in about 6.35 seconds of simulation time. The browser issued zero external requests or page errors. Windows Explorer launched the exact HTML, and the round started in windowed Chrome.

The evidence package records the measured revision, playable SHA-256, browser and environment, individual scenarios, test exit codes and artifact paths. At a 1230 × 691 Canvas 2D backing size, headless software Chrome measured a 49.9 ms median frame and 50.0 ms p95 across 25 samples. This configuration missed the 60 FPS target.
